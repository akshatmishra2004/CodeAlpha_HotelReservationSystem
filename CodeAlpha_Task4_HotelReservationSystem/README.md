# CodeAlpha Task 4 — Hotel Reservation System

## Features
- Search available rooms by dates
- Room categories: Standard, Deluxe, Suite
- Room pricing
- Book rooms
- Cancel reservations
- View booking details
- Simulated payment
- Prevents overlapping bookings
- OOP design using Room and Reservation classes
- File I/O persistence using `hotel_data.dat`

## Run
```bash
javac Main.java
java Main
```

Dates must be entered in `yyyy-MM-dd` format, for example `2026-10-10`.
